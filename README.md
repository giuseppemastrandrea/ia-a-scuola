# IA a scuola: catalogo dei moduli

Sito statico per la formazione dei docenti sull'IA generativa: 19 moduli con esercitazioni pratiche, prompt pronti e un prodotto per ogni modulo, composti in 5 corsi (base 9h, intermedio 6h, da zero 17h e 30h, agenti 6-8h).

Si apre `index.html` nel browser: non serve build.

| Percorso | Contenuto |
|---|---|
| `index.html` | Catalogo: moduli (vista a griglia o elenco), filtro per corso, composizione dei corsi, rassegna stampa |
| `materiali/compliance/` | Mappa per il docente, vademecum, slide "Quattro strati, undici domande" (HTML e PDF) |
| `materiali/intro-ai/` | Deck MARP "Introduzione all'IA e all'IA generativa" (sorgente `.md`, HTML, PDF, immagini) |
| `materiali/apps-script/` | `genera-form-quiz.gs`: genera un Google Form quiz dalle variabili `CONFIG` e `DOMANDE` (modulo M08) |
